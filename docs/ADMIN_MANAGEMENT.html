Managing admin access

Admins use the app's existing officer role. Any current officer can grant the same access to another registered user.

Make someone an admin

  1. Have the person sign in once so their account appears in the app.
  2. Open Officer tools, then Manage admins (/officer/administrators).
  3. Search by name or email and check the account's email address.
  4. Select Make admin and confirm the account and access.

The page confirms the change and shows Admin (officer). That person can now open officer tools and manage events, attendance, points, reports, and other admins. They may need to refresh their page.

Promotion preserves the person's attendance and point adjustment records, but they stop earning member points, including from past records. They are excluded from member points reports.

Access and persistence

Members and signed-out visitors cannot list accounts here or grant admin access, even by submitting the request directly. Existing admins are labelled as admins and have no promotion button. Repeating a promotion is safe.

Grants are stored in the application's database and survive later sign-ins. An account promoted in dev must be promoted separately in production if the environments use different databases.

First admin and access removal

The existing OFFICER_EMAILS configuration still provides initial admin access. This page grants access; access removal continues to use the existing operational process: remove the email from OFFICER_EMAILS and change the saved user's role to member. Both steps are needed for an allowlisted account.
